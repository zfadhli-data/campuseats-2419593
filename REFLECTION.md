# Week 1 reflection

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
Imperative DOM code tells the browser step by step what to do. React describes the UI state and React handles the updates automatically.

2. Why must a component name start with a capital letter? 
To distinguish components from HTML tags, ensuring it can display correctly.

3. What does a fragment <>...</> do, and why not just use a <div>? 
A fragment groups elements without adding extra nodes. <div> introduces unnecessary wrappers.

4. Name one benefit of splitting the UI into small components. 
Improves reusability and easy to maintain and test the code.
